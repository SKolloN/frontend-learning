# SKolloN Lab

Личный сайт Вадима, который развивается вместе с обучением frontend-разработке.

`SKolloN Lab` — это  frontend-лаборатория: пространство, где WordPress-опыт, JavaScript, дизайн и эксперименты постепенно превращаются в настоящие frontend-проекты.

## Главная идея

Показать путь от WordPress/CMS-разработки к современному frontend-разработчику.

Сайт не типичная корпоративная визитка, а личное пространство, с доступом для желающих, основной тон сайта и характер:

- цветной
- спокойный
- дружелюбный
- мягкий
- немного игровой
- понятным для работодателя
- не перегруженным декоративными элементами

## Название и личный бренд

Основное название сайта: `SKolloN Lab`.

`SKolloN` — личный псевдоним меня, Вадима.

На сайте псевдоним используется как личный frontend-бренд, но сайт не скрывает реального человека за ним.

Предварительный логотип:

- текст: `SKolloN Lab`




## Настроение

Сайт должен ощущаться как уютная лаборатория кода.

Не стерильная лаборатория, а мягкое пространство, где можно экспериментировать, учиться и собирать интерфейсы.

Ключевые ощущения:

- уют
- тепло
- мягкость
- спокойствие
- любопытство
- живой процесс обучения
- аккуратные эксперименты

## Визуальный стиль

Основной образ:

- кремовый фон
- шоколадный текст
- мятный акцент
- персиковые детали
- лавандовые декоративные элементы
- мягкие скругления
- карточки как заметки/стикеры
- декоративные элементы в стиле пузырьков, искр и маленьких экспериментов

## Цветовая идея

Основные цвета:

- кремовый фон
- шоколадный текст
- мятный акцент Jelly Mint
- мягкий персиковый
- мягкий лавандовый

Цвета не должны спорить с контентом.  
Акценты используются дозированно: кнопки, бейджи, декоративные элементы, hover-эффекты.

## Шрифты

Предварительная идея:

- акцентный шрифт: Pattaya
- основной шрифт: Nunito

Акцентный шрифт используется только для логотипа, отдельных слов или декоративных фраз.

Основной текст должен быть хорошо читаемым.

## Подход к верстке

Сайт строится на гибкой адаптивной верстке с ограниченным контейнером.

Основной подход:

- mobile-first
- резиновый контейнер с максимальной шириной
- `clamp()` для плавных размеров шрифтов и отступов
- `grid` и `flex` для сеток
- минимум фиксированных размеров
- media queries только там, где сетка реально должна перестроиться

Ориентир дизайна — экран 1440px, но верстка не фиксируется под 1440px.

## Контейнер

- максимальная ширина контейнера: 1280px
- мобильные отступы по бокам: 16px
- планшетные отступы по бокам: 24px
- десктопные безопасные поля: 48px
- контент не растягивается бесконечно на больших экранах

## Система отступов

Используется 8-point grid.

Основные значения:

- 8px
- 16px
- 24px
- 32px
- 40px
- 48px
- 64px
- 80px
- 96px
- 120px
- 144px
- 160px
- 176px

## Правила отступов

Родственные элементы располагаются близко друг к другу:

- заголовок и подзаголовок: 8–16px
- заголовок секции и описание: 16–24px
- текст и кнопки: 24–32px

Внутренний отступ карточек, кнопок и блоков должен быть больше, чем расстояния между связанными элементами внутри них.

Расстояние между разными смысловыми блоками должно быть большим и воздухопроницаемым:

- на мобильных: 64–96px
- на десктопе: 120–180px

## Структура страницы

Основные секции:

1. Header — легкая навигация поверх hero без коммерческого top bar.
2. Hero — первый экран с главным сообщением, кнопками и декоративной карточкой текущего обучения.
3. About — короткий рассказ о том, кто я и откуда пришел в frontend.
4. Path — путь от дипломной HTML/CSS-работы и WordPress к JavaScript, React и TypeScript.
5. Skills — текущие навыки, разделенные по группам.
6. Projects — учебные и реальные проекты.
7. Work approach — как меняется мой рабочий процесс: от FTP-правок к Git и нормальной разработке.
8. Contacts — способы связаться: Email, Telegram, GitHub.
9. Footer — короткая финальная подпись.

## Header

Шапка не должна выглядеть как коммерческий top bar.

Основная идея:

- логотип/текстовый знак слева
- якорная навигация по секциям
- легкий внешний вид без тяжелого фона
- визуально является частью hero-секции
- на мобильных позже появится burger-menu

Навигация:

- Обо мне
- Путь
- Навыки
- Проекты
- Контакты

## Контакты

В первой версии используются простые ссылки:

- Email через `mailto:`
- Telegram через внешнюю ссылку
- GitHub через внешнюю ссылку

Форма обратной связи не добавляется в первой версии.

Позже можно реализовать ее через:

- внешний form-сервис
- backend/API
- Next.js API route
